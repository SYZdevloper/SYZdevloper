#### 🌾 [Industry Insights Platform](https://github.com/SYZdevloper) — Jun 2026 – Present
*Next.js 14, TypeScript, Cloudflare, Drizzle ORM, AI APIs*

A 22-vertical multi-tenant market intelligence SaaS platform, architected as a Turborepo monorepo with each app backed by a dedicated Cloudflare D1 database, R2 media bucket, and custom domain — fully serverless and edge-deployed with zero traditional servers.

- Designed a 30+ table relational schema (Drizzle ORM, SQLite) powering an AI-driven content pipeline: automated report generation, webhook-triggered news/blog creation, a QStash-based drip scheduler, and a 27-endpoint system for web crawling, duplicate detection, and health monitoring
- Built 35+ reusable React report-block components (market sizing, SWOT, Porter's Five Forces, interactive charts) with Excel/PDF export
- Shipped an admin CMS with RBAC/audit logging, multi-gateway checkout (Stripe, PayPal, Razorpay), and automated cross-vertical deployment via Wrangler CLI and the OpenNext Cloudflare adapter

#### 🏡 SoulHome Membership Platform — Feb 2026 – Aug 2026

A full-stack educational and membership platform with role-based access across public, dashboard, and admin routes.

- Architected relational data modeling on AWS RDS (PostgreSQL) with AWS Cognito for RBAC
- Engineered an end-to-end Stripe payment and enrollment workflow processing 50+ course purchases, with automated email confirmations via serverless AWS Lambda and Resend
- Built a Tiptap-based admin CMS for blogs and digital resources backed by AWS S3 media storage
- Implemented a waitlist and lead-generation system using AWS CloudFront and Next.js SSR for fast, conversion-optimized marketing pages

#### 🎤 AI Mock Interview Platform — Dec 2025 – Jul 2026
